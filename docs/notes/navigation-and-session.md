# Navigation & session (how it works)

- **Login state is state; only AppRoot turns it into navigation.** `MainViewModel.session` (`Loading / LoggedIn / LoggedOut`) is created Activity-scoped in `AppRoot.kt`. AppRoot has a top-level NavHost (`AppRootScreens.SplashTopLevel / AuthTopLevel / MainTopLevel`), and one `LaunchedEffect(session)` navigates there with `popUpTo(graph.id){inclusive=true}`.
- **Why navigate instead of `when(session)`:** popping a back stack entry clears every ViewModel inside it, including the nested NavHost's screens. A plain `when` leaves them alive in the Activity store (NavHost doesn't clear on dispose, checked in the nav 2.8.0-beta04 source). Keep the top-level NavHost.
- `AppRootScreens` is deliberately **not** a `NavigationScreens`, so no ViewModel can `OnNavigate` to it.
- **Login:** `AuthViewModel` sends `OneTimeEvents.OnLoginOrRegisterCompleted` after login/register fully finishes → `LoginScreen`/`RegisterScreen` `onLoginOrRegisterCompleted` → `MainViewModel.onLoginOrRegisterCompleted()`. It's explicit because Firebase signs in *before* `RegisterUseCase` saves the display name.
- **Logout:** never navigate. Just call `profileRepository.logout()` (or delete the account). `MainViewModel.observeSignOut()` (Firebase `AuthStateListener` through `AuthService.observeAuthState()`) sets LoggedOut and clears DataStore. `NoUserException` handlers just call `logout()`.
- **Startup:** `MainViewModel.checkCurrentUser()`. A network error still means LoggedIn if Firebase has a cached user.
- **Inner navigation:** screens get `onNavigate(route, NavOptions?)` / `onPopBackStack`. VMs send `OnNavigate(route, NavBehavior)`, and screens call `event.behavior.toNavOptions()` (`navigation/NavBehavior.kt`). `NavBehavior` = `None | PopUpTo(dest, inclusive)`.
- **Shell (`MainScreen.kt`):** one Scaffold. The top/bottom bar visibility, the title and the selected tab are all derived from `currentBackStackEntry` with `hasRoute`/`hierarchy`. Never keep a separate "selected tab" variable. Tabs use the standard `popUpTo(start){saveState}` + `restoreState`. The name/photo come from `MainViewModel.user` (a DataStore flow).
- **Adding a screen with a title:** add a branch in `topBarTitle()` plus a string under `<!-- MAIN SCREEN -->`. If it's in a new graph and needs the top bar, add it to `showTopBar`.
