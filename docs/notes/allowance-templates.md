# Allowance templates (how it works)

- **What it is:** a saved set like "Weekday: Food ₱300, Transportation ₱150". Tapping it in the Add Allowance sheet (after a confirm dialog) adds one allowance per row for **today**, in one batch (`addTransactions`). Each is titled with the template name, description `"---"`, and can be edited or deleted like any allowance.
- **Stored in its own collection: `allowance_templates/{uid}`** with `userId` and a `templates` list (`AllowanceTemplatesDoc`, `AllowanceTemplateModel`, `AllowanceTemplateItem`, all `@Keep`). It was first a field on `users/{uid}` and was moved out: templates are a separate module the user can live without, not profile data (see the `firebase-firestore-data-modeling` skill). Old templates on `users/{uid}` were not migrated.
- **Rules:** owner read/write on `allowance_templates/{uid}`. `deleteUserData` deletes it with the account.
- **Save writes the whole list** (`saveAllowanceTemplates`, `set` with merge; arrays are replaced as a whole). Adding, editing and deleting all compute the new list in `AddViewModel` and save through it. **Guard:** save and delete wait for `hasLoadedTemplates`, otherwise a save before the first load would wipe the stored list.
- **Validation** in `TransactionRepository.saveAllowanceTemplates`: a name, at least one row, and each row needs a category and amount > 0.
- **Listener:** `templatesJob` in `AddViewModel`, started on the Add tab's ON_START (only if not active) and on pull-to-refresh. One VM per module, so `AllowanceTemplatesScreen` uses `AddViewModel` too.
- **Editor (`AllowanceTemplatesScreen`):** the draft lives in VM state (`templateDraft`), so it survives rotation. A "Categories" header with the total, then one line per row with dividers: red X (only red when there's more than one row) → private `CategoryPicker` (weight 1, ellipsizes but stays tappable) → `CurrencyTextField` (weight 2, `singleLine`). A spinner shows until the first load.
- **Sheet (`AddAllowanceSheetContent`):** "Custom allowance" (the normal form) on top, then a 2-column `LazyVerticalGrid` of outlined template cards and a dashed "New template" card. Grey placeholders while loading, a hint when there are none. Cards show up to 2 categories joined with "  •  ", otherwise a count.
